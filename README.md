# Projek Tangan — Hand Gesture Video

## Isi folder

- `index.html` — halaman utama
- `style.css` — tampilan
- `script.js` — kontrol video + hand tracking
- `video.mp4` — video kamu (tambahkan sendiri)

## Cara upload ke GitHub Pages

1. Pastikan file video kamu bernama `video.mp4`.
2. Upload `index.html`, `style.css`, `script.js`, dan `video.mp4` ke root repository.
3. Buka Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`.
6. Folder: `/ (root)`.
7. Save.
8. Buka URL GitHub Pages repository kamu.

## Gesture

- ☝️ 1 jari → Play
- ✊ Kepalan → Pause
- 🖐️ 5 jari → Mute / unmute
- ✌️ 2 jari → Maju 5 detik
- 🤟 3 jari → Mundur 5 detik

## Catatan

Kamera membutuhkan izin browser dan sebaiknya dijalankan melalui HTTPS.
GitHub Pages menggunakan HTTPS, jadi cocok untuk proyek ini.

MediaPipe dimuat dari jsDelivr CDN, sehingga internet diperlukan saat halaman pertama kali dibuka.
